# 1.x 界面统一化记录

> 本文对应 `docs/roadmap-1.x.md` 的 `[UI][P5]`，记录统一化边界、实施批次和验收结论；它不替代工作清单或 Changelog。

## 目标与边界

目标是让用户在首页、Blog、Knowledge、Projects 与 About 之间切换时，能感受到同一套排版节奏、控件尺度和玻璃材质层级，而不是把所有页面压成同一种布局。

- Blog 保持按日期阅读的紧凑文章流。
- Knowledge 保持带分类、状态、版本与标签的资料流，并因侧栏使用更宽的内容容器。
- Projects 保持较宽松的展示卡片网格。
- 首页 Dashboard 是仪表盘式个人表达，保留 `rounded-3xl` 与显式网格作为特例。

因此，“统一”只作用于相同职责的元素：页面标题区、工具条、卡片材质、交互状态与触控尺寸；不同内容类型不强制使用相同卡片高度。

## 当前审阅

- Blog、Knowledge 与 Projects 的主体卡片均已使用玻璃材质，但圆角、内边距、边框透明度和阴影仍各自定义。
- Blog 的搜索框为 44px，而排序分段控件因内外间距实际为 56px；归档切换又是另一种高度，工具条基线不稳定。
- Knowledge 的分类按钮已经满足 44px 触控尺寸，但排序控件与 Blog 缺少共同的布局容器。
- 排序控件的“标题／最后更新／升降序”均是明确文字状态。为避免引入与筛选控件不一致的图标语言，本轮继续不用图标；三个固定宽度分段也避免中文文案长度导致相邻元素移动。

## 统一规则

| 元素 | 规则 |
| --- | --- |
| 页面标题区 | 默认内容页使用 `py-16`，标题后保留 8px 摘要间距，内容区从标题区后 32px 开始。Knowledge 的 `max-w-6xl` 是为分类侧栏保留的刻意差异，其余内容页默认 `max-w-5xl`。 |
| 工具条 | 外部视觉高度 52px；可点击的主按钮不小于 44px；相邻操作保留至少 8px 间距。窄屏可换行，但不可横向截断。 |
| 排序 | 两个排序依据与一个方向按钮固定为三个 80px 分段。高亮仅表示当前依据，方向按钮保留清晰文字和辅助说明。 |
| 内容卡 | 后续统一为 `rounded-2xl`、同一边框/表面层级和 `p-5 sm:p-6` 的内边距阶梯；同一列表内可按内容类型预留最小高度，不跨页面强制等高。 |
| 展示与仪表盘卡 | Projects 与 Dashboard 可保留独立高度、网格和圆角，但复用颜色、边框、focus 与 hover 规则。 |
| 交互 | 颜色变化在 150–300ms 内完成；不通过宽高动画或不同字长推动邻近控件；键盘焦点始终可见。 |

## 实施批次

### 第一阶段：内容工具条

- 新建共享工具条容器，统一 Blog 与 Knowledge 中工具操作的换行、对齐和间距；窄屏排序控件维持自身固定宽度并与搜索框左缘对齐，不拉伸成整行。
- 将 Blog 搜索、归档切换与共用排序控件对齐为 52px 外部节奏；排序内按钮保持 44px 点击目标。
- 将 Blog 标签筛选在手机端提升到 44px 点击高度，桌面端维持紧凑展示。
- 不改变排序逻辑、分类逻辑、内容顺序或已有视觉主题。

验收：在 390px 与桌面宽度下，Blog 与 Knowledge 的工具操作不溢出；切换排序、归档、标签或输入搜索时不推动相邻控件；明暗主题下焦点和当前状态清晰可辨。

### 第二阶段：内容卡片

- 收敛 Blog、Knowledge、Projects 的卡片表面、边框、圆角、内边距和 hover/focus 反馈。
- 分别定义文章流、知识资料流与项目展示卡的内部排版与最小高度，不把三者做成同高。

### 第三阶段：特殊面板与回归

- 审阅 Dashboard、About、Footer 与文章详情，只应用可共享的材质和交互规则。
- 在明暗主题、390px、768px、1024px、1440px 与静态导出产物中回归检查。

## 第一阶段结果

- 已新增 `ContentToolbar`，供 Blog 与 Knowledge 共用响应式工具操作布局；桌面端左右对齐，窄屏自动纵向排列。
- Blog 搜索框、归档切换与排序外壳统一为 52px 外部高度；排序内部三个固定 80px 分段均保留 44px 点击高度。
- Blog 标签筛选在窄屏为 44px 点击目标，在 `sm` 及以上恢复紧凑高度；Knowledge 分类按钮沿用既有 44px 基线。
- 窄屏排序控件不再因弹性容器的默认拉伸而横跨整行；桌面端仍沿内容区右侧对齐。
- 已通过本轮组件 ESLint 检查与 `npm run build`；在 `out/` 静态预览中检查 Blog 和 Knowledge 的桌面工具条对齐。
- 待本地在 390px、明暗主题及真实触控环境中确认后，再进入第二阶段内容卡片统一。

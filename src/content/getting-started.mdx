Welcome to the new site.

This space is where I'll be writing about embedded systems, software development, and whatever else catches my attention.

## Why a new site?

After years of using WordPress with third-party themes, I hit a wall. Customisation was always a fight — the theme author's opinions baked into every template, the block editor fighting back when I tried to write my way, and the overhead of a database-driven CMS for a site that really just needs flat files and a build step.

So I rebuilt.

## The stack

- **Next.js 16** — full-stack React framework, App Router
- **MDX** — blog posts are Markdown files with JSX when needed
- **Tailwind CSS v4** — utility-first styling
- **Framer Motion** — animations
- **Docker** — self-hosted on a 2C4G VPS

## What's next

The blog will follow my learning: embedded Rust, RTOS concepts, build systems, and the occasional tangent into web development.

Check back, or don't — the internet archive will keep this safe either way.

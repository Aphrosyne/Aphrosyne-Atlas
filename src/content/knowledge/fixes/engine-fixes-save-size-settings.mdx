> 本文是基于 SSE Engine Fixes 7.0.19 的个人配置笔记，并参考社区帖子。不同游戏版本、模组组合与配置可能表现不同，应先备份存档再调整。

## 适用问题

- 长时间游玩后存档无法读取或读档崩溃。
- 游戏过程中偶发“存档错误”，重启后又能读入的假性坏档。
- 动画限制或 Havok 内存管理导致的稳定性问题。

## 建议核对项

### `bAnimationLoadSignedCrash = false`

若另行安装 `Animation Limit Crash Fix SSE`，可关闭 Engine Fixes 自带的动画限制崩溃修复以避免功能重叠；未使用该模组时，此项应保持 `true`。实际值须按安装组合决定。

### `bRegularQuicksaves = true`

将 F5 快速保存改为常规保存，便于频繁保存时避开快速保存相关风险。仍建议保留多个手动存档，不把它视为存档损坏的通用修复。

### `iSaveGameMaxSize = 512`

记录中的值为 512，用于提高**未压缩**存档大小上限。不要根据 `.ess` 文件本身的压缩后大小判断；可在 ReSaver 中查看 `Total size`。旧版 Engine Fixes 的较低默认上限可能导致较大的存档无法读取。

### `bOverrideHavokMemorySystem = false`

Engine Fixes 7 新引入的 Havok 内存管理在部分组合中可能触发崩溃；若遇到相关问题，可在备份后尝试关闭并做对照测试。

## 排查边界

存档损坏、DLL 兼容性、加载顺序、插件数量与模组脚本都可能造成相似现象。本文配置不是对所有读档失败的确定修复；修改前应备份，并以可复现的单变量测试确认效果。

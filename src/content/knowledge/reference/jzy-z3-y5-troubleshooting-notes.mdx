## 自定义前缀

- `a+`：新增（add）。
- `c+`：修改过原模组，例如配置文件或 ESP 内容（change）。
- `u+`：原模组版本过旧后的更新（update）。

## 常见排查

### RaceMenu 身体比例中文异常

原记录认为部分 XP32 最大骨骼汉化的格式会导致比例文本显示异常。可对照其他汉化或旧版翻译文件，检查 `Chinese` 与 `English` 翻译文件的结构和编码；修改前备份原文件。

### 沉浸式装备展示显示问号

在 UI 设置中将字体切换为 `YaHei UI`，并启用 `Extra glyphs` 的 `Chinese full`，以补齐中文字符。

### OAR 大剑拔刀抽动

原记录建议停用 Smooth Moveset 的 `2hm` 与 `2hm no-combat idle start` 条目后复测。

### 假发转真发时缺少物理碰撞

Outfit Studio 导出的 NIF 文件名应与工程中部件名、XML 所引用的模型名保持一致，例如 `VirtualGround`、`VirtualCBBE`、`VirtualHead` 等。文件名不一致时，物理碰撞配置可能无法匹配。修改前应对照目标发型的 XML 与 ESP 记录逐项验证。

### 常用定位

- 当前位置传送：先在目标地点存档，再从存档名获取地点英文标识，以 `COC` 验证传送位置。
- 物品寻找器：原始默认键记录为 `Shift+Q`，菜单键为 `Insert`；实际键位以当前 MCM 为准。
